# CV Koçu

CV metnini yapıştırıyorsun, araç eksiklerini gösterip bir puan veriyor.

Canlı hali: [github pages linkin]

## Ne kontrol ediyor

- CV'nin uzunluğu
- E-posta ve telefon var mı
- Eğitim, deneyim, beceri ve proje bölümleri var mı
- "Ben ... yapıyorum" gibi CV'ye uymayan anlatım
- Rakamla somutlaştırma
- Fazla boşluk, art arda ünlem gibi küçük hatalar

Metin tarayıcıda kalıyor, hiçbir yere gönderilmiyor.

## Nasıl yapıldı

HTML, CSS ve JavaScript ile yazıldı. Sunucu yok, tek dosya. Kodu yazarken yapay zekâdan yardım aldım, ne kontrol edileceğine ve nasıl çalışacağına ben karar verdim.

## Sırada ne var

- Yapay zekâ ile CV'yi iyileştirme özelliği
- Mülakat sorularıyla prova
- İngilizce CV desteği
